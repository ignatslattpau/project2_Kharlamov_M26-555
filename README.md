## Управление таблицами

Проект `primitive_db` — простая консольная база данных на Python.

Программа позволяет создавать, просматривать и удалять таблицы. Информация о структуре таблиц хранится в JSON-файле `db_meta.json`.

### Установка и запуск

Установите зависимости проекта:

```bash
uv sync
```

Запустите базу данных:

```bash
uv run database
```

### Поддерживаемые команды

| Команда | Описание |
|---|---|
| `create_table <имя> <столбец:тип> ...` | Создать таблицу |
| `list_tables` | Показать список таблиц |
| `drop_table <имя>` | Удалить таблицу |
| `help` | Вывести справку |
| `exit` | Завершить программу |

Поддерживаемые типы данных: `int`, `str`, `bool`.

При создании таблицы автоматически добавляется столбец `ID:int`, если пользователь не указал его самостоятельно.

### Пример использования

```text
>>>Введите команду: create_table users name:str age:int
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int

>>>Введите команду: list_tables
- users

>>>Введите команду: drop_table users
Таблица "users" успешно удалена.

>>>Введите команду: exit
```

### Хранение данных

Структура созданных таблиц сохраняется в файле `db_meta.json`. При повторном запуске приложения метаданные загружаются автоматически.

### Сборка пакета

```bash
uv build
uvx twine check dist/*
```

## CRUD-операции

В проекте `primitive_db` реализована работа с данными таблиц: создание, чтение, обновление и удаление записей.

### Установка

Установите зависимости:

```bash
uv sync
```

Запустите программу:

```bash
uv run database
```

### Команды

| Команда | Описание |
|---|---|
| `create_table <имя> <столбец:тип> ...` | Создание таблицы |
| `list_tables` | Просмотр списка таблиц |
| `drop_table <имя>` | Удаление таблицы |
| `insert into <имя> values (...)` | Добавление записи |
| `select from <имя>` | Вывод всех записей |
| `select from <имя> where <поле> = <значение>` | Выборка по условию |
| `update <имя> set <поле> = <значение> where <условие>` | Обновление записей |
| `delete from <имя> where <условие>` | Удаление записей |
| `info <имя>` | Информация о таблице |
| `help` | Справка |
| `exit` | Завершение программы |

### Поддерживаемые типы данных

- `int` — целые числа
- `str` — строки
- `bool` — логические значения

Строковые значения вводятся в кавычках. Все поля обязательны. Поле `ID` генерируется автоматически.

### Пример работы

Создание таблицы:

```text
create_table users name:str age:int is_active:bool
```

Добавление записи:

```text
insert into users values ("Sergei", 28, true)
```

Получение всех записей:

```text
select from users
```

Поиск по условию:

```text
select from users where age = 28
```

Изменение данных:

```text
update users set age = 29 where name = "Sergei"
```

Удаление записи:

```text
delete from users where ID = 1
```

Просмотр информации о таблице:

```text
info users
```

### Хранение данных

Метаданные таблиц сохраняются в `db_meta.json`.

Записи каждой таблицы хранятся в отдельном JSON-файле внутри директории `data/`.

Например:

```text
data/
├── users.json
└── products.json
```

Изменения сохраняются после успешного выполнения операций INSERT, UPDATE и DELETE.
