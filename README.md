## Управление таблицами

Проект `primitive_db` — простая консольная база данных на Python.

Программа позволяет создавать, просматривать и удалять таблицы. Информация о структуре таблиц хранится в JSON-файле `db_meta.json`.

### Установка и запуск

Установите зависимости проекта:

```bash
uv sync
```

Запустите базу данных:

```bash
uv run database
```

### Поддерживаемые команды

| Команда | Описание |
|---|---|
| `create_table <имя> <столбец:тип> ...` | Создать таблицу |
| `list_tables` | Показать список таблиц |
| `drop_table <имя>` | Удалить таблицу |
| `help` | Вывести справку |
| `exit` | Завершить программу |

Поддерживаемые типы данных: `int`, `str`, `bool`.

При создании таблицы автоматически добавляется столбец `ID:int`, если пользователь не указал его самостоятельно.

### Пример использования

```text
>>>Введите команду: create_table users name:str age:int
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int

>>>Введите команду: list_tables
- users

>>>Введите команду: drop_table users
Таблица "users" успешно удалена.

>>>Введите команду: exit
```

### Хранение данных

Структура созданных таблиц сохраняется в файле `db_meta.json`. При повторном запуске приложения метаданные загружаются автоматически.

### Сборка пакета

```bash
uv build

```
