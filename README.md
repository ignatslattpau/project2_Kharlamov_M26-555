# Primitive DB

**Primitive DB** — учебная консольная база данных на Python, поддерживающая создание и удаление таблиц, CRUD-операции, хранение данных в JSON-файлах, обработку ошибок, декораторы и кэширование запросов.

Проект разработан с использованием Python 3.12 и пакетного менеджера `uv`.

## Возможности

- Создание таблиц с заданными столбцами и типами данных.
- Просмотр и удаление существующих таблиц.
- Добавление, чтение, обновление и удаление записей (CRUD).
- Автоматическая генерация идентификаторов записей `ID`.
- Проверка корректности типов данных.
- Сохранение метаданных и записей в JSON-файлах.
- Вывод данных в табличном формате через `PrettyTable`.
- Обработка исключений с помощью декораторов.
- Подтверждение удаления таблиц и записей.
- Измерение времени выполнения операций.
- Кэширование результатов запросов `SELECT`.

## Технологии

- **Python 3.12** — язык программирования.
- **uv** — управление зависимостями, виртуальным окружением и сборкой.
- **prompt** — взаимодействие с пользователем через консоль.
- **PrettyTable** — форматирование табличного вывода.
- **JSON** — хранение метаданных и записей.
- **Ruff** — проверка качества кода.

## Установка

Для работы с проектом необходим Python 3.12 и установленный пакетный менеджер `uv`.

Склонируйте репозиторий:

```bash
git clone <URL_РЕПОЗИТОРИЯ>
```

Перейдите в директорию проекта и установите зависимости:

```bash
uv sync
```

## Запуск

Для запуска базы данных выполните:

```bash
uv run database
```

После запуска программа выведет список доступных команд.

## Управление таблицами

| Команда | Описание |
|---|---|
| `create_table <имя> <столбец:тип> ...` | Создание таблицы |
| `list_tables` | Просмотр списка таблиц |
| `drop_table <имя>` | Удаление таблицы |
| `help` | Вывод справочной информации |
| `exit` | Завершение программы |

Поддерживаемые типы данных:

- `int` — целые числа.
- `str` — строки.
- `bool` — логические значения.

При создании таблицы автоматически добавляется столбец `ID:int`, если пользователь не указал его самостоятельно.

Пример создания таблицы:

```text
create_table users name:str age:int is_active:bool
```

Результат:

```text
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
```

Просмотр таблиц:

```text
list_tables
```

Результат:

```text
- users
```

## CRUD-операции

Программа поддерживает четыре основные операции для работы с записями: Create, Read, Update, Delete.

### INSERT — добавление данных

```text
insert into users values ("Sergei", 28, true)
```

Результат:

```text
Запись с ID=1 успешно добавлена в таблицу "users".
```

Столбец `ID` заполняется автоматически и не передаётся в команде INSERT.

Все остальные поля обязательны.

### SELECT — чтение данных

Вывод всех записей:

```text
select from users
```

Вывод записей по условию:

```text
select from users where age = 28
```

Результат отображается в виде таблицы с помощью PrettyTable.

### UPDATE — обновление данных

```text
update users set age = 29 where name = "Sergei"
```

Результат:

```text
Запись с ID=1 в таблице "users" успешно обновлена.
```

### DELETE — удаление данных

```text
delete from users where ID = 1
```

Перед выполнением операции программа запрашивает подтверждение.

### INFO — информация о таблице

```text
info users
```

Результат:

```text
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0
```

## Хранение данных

Метаданные таблиц сохраняются в файле `db_meta.json`.

Записи каждой таблицы хранятся в отдельном JSON-файле директории `data/`.

Пример структуры:

```text
data/
├── users.json
└── products.json
```

Для работы с JSON используются стандартные функции `json.load()` и `json.dump()`.

Загрузка и сохранение данных реализованы в модуле `utils.py`.

## Декораторы и замыкания

### Обработка ошибок

Декоратор `handle_db_errors` централизованно обрабатывает исключения:

- `FileNotFoundError`
- `KeyError`
- `ValueError`

При возникновении ошибки выводится соответствующее сообщение.

### Подтверждение опасных операций

Декоратор `confirm_action(action_name)` применяется к операциям удаления таблиц и записей.

Пример:

```text
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]:
```

При вводе `y` операция выполняется. При другом ответе операция отменяется.

### Измерение времени

Декоратор `log_time` измеряет время выполнения функций с помощью `time.monotonic()`.

Он применяется к операциям `insert` и `select`.

Пример вывода:

```text
Функция select выполнилась за 0.001 секунд
```

### Кэширование запросов

Функция `create_cacher()` реализует кэширование с использованием замыкания.

При повторном выполнении запроса с одинаковыми данными и условием результат берётся из кэша.

Ключ кэша учитывает содержимое таблицы и условие запроса, что позволяет избежать использования устаревшего результата после изменения данных.

## Архитектура проекта

```text
src/
└── primitive_db/
    ├── __init__.py
    ├── main.py
    ├── engine.py
    ├── core.py
    ├── parser.py
    ├── utils.py
    ├── decorators.py
    └── constants.py
```

Назначение модулей:

| Модуль | Назначение |
|---|---|
| `main.py` | Точка входа в приложение |
| `engine.py` | Основной цикл и обработка команд |
| `core.py` | Логика управления таблицами и CRUD |
| `parser.py` | Разбор пользовательских команд |

| `decorators.py` | Декораторы и кэширование |
| `constants.py` | Константы проекта |

## Проверка качества кода

Для проверки стиля используется Ruff.

Запуск проверки:

```bash
uv run ruff check .
```

Конфигурация Ruff находится в `pyproject.toml`.

## Сборка пакета

Для создания дистрибутивов выполните:

```bash
uv build
```

Результат сборки сохраняется в директории `dist/` в форматах `.whl` и `.tar.gz`.

Для проверки метаданных:

```bash
uvx twine check dist/*
```

Для установки собранного пакета:

```bash
uv tool install --force dist/*.whl
```

После установки программа доступна через команду:

```bash
database
```

1. Запуск приложения.
2. Создание таблицы.
3. Добавление записей.
4. Выборку данных.
5. Обновление записи.
6. Удаление записи с подтверждением.
7. Удаление таблицы.
8. Обработку некорректных команд.

**Asciinema:** ссылка на опубликованную запись будет добавлена здесь.
